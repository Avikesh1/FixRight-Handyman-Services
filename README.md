# FixRight Handyman Website

A responsive, mobile-first handyman service website prototype.

## Run it
Open `index.html` in a browser, or serve the folder with any static web server.

## Current features
- Responsive homepage
- Services
- About / service coverage
- Work showcase
- Quote request form with demo confirmation
- WhatsApp CTA
- Mobile navigation
- SEO metadata

## Before launch
Replace the demo phone/email, connect the quote form to a backend/email/CRM, add real project photos, configure the WhatsApp number, domain and hosting, and add any required business/legal information.
